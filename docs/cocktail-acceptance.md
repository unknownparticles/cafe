# 鸡尾酒 MVP 验收（2026-10-14）

## 内容与构建

- 原有 60 张咖啡/甜品数据与 HEAD 的前 60 张逐对象比对一致；新增 15 张鸡尾酒、39 种材料。
- 逐条查阅 15 张 IBA 原页，记录来源与家庭参考值；不转载外部正文/图片，酒谱尚未实际调酒测试。
- 全库 274 步、811 场景，新增摇和/搅拌/过滤/分层/加冰/补饮料/装饰/揭晓模板，复用原播放器。
- `npm run build` 检查类型、75 张配方、材料别名/引用、来源、资源与动画参数，并生成包含材料库的 Service Worker。

## 临时逻辑验证

使用临时编译后的真实 TypeScript 服务和 Node assert，验证后删除临时测试与产物：

- 别名准确映射，青柠不自动算青柠汁。
- 缺少基酒和待确认材料不能显示齐全。
- 排除材料不出现在配方，锁定材料必须进入；无法匹配时返回空结果。
- 无酒精排除酒精材料，低酒精拒绝未知酒精度或估算超过 8% 的酒款。
- 生成配方全部使用已确认库存，使用统一详情结构与动画，变体/实验均为未实测。
- 空库存不生成酒谱；估算纯酒精体积与稀释公式按预期计算。
- 备份拒绝空步骤、外部素材 URL、未知收藏引用、超范围评分，以及数组伪装的酒精/购物/制作状态枚举。
- 独立代码审查指出枚举强制转字符串漏洞；已增加真实类型检查并以失败/通过测试确认修复。

## 浏览器验证

Codex 内置浏览器、生产预览 `/cafe/`：

- 首页显示第三品类与材料调酒入口；鸡尾酒分类抽卡与详情能打开。
- 选择 7 种材料实时更新推荐；约翰柯林斯正确显示必需材料齐全、装饰可省，缺少工具的酒款单独提示。
- 只用已有 + 无酒精显示两张零酒精气泡实验配方，无含酒精经典酒谱。
- 生成配方详情使用统一播放器；加冰动画可暂停。
- 保存生成酒谱为收藏，标记已制作、4/5 评分与备注，刷新后重新打开仍保留。
- 导出实际 JSON 文件，重新选择该文件，显示 1 个收藏/1 张创意酒谱/1 条记录/7 种材料的预览，确认后成功导入。
- 停止本地预览服务器后刷新，PWA 从缓存打开材料页、继续生成配方、打开创意收藏并读取备注。
- 390×844 手机视口：首页卡片完整，4 个分类按钮均为 44px 高；首页和材料页无横向溢出。
- 已检查浏览器错误/警告日志，未发现应用错误。

## 边界

桌面浏览器模拟手机视口不替代 iOS/Android 真机。此记录不代表实际调酒、实测酒精度或口感保证。尚未提交、推送或部署；线上 GitHub Pages 仍须发布后验收。构建沿用现有 `/cafe/`、hash 导航和版本缓存策略。

## 四步材料选择增量验收

- 四个 Tab 顺序为基酒、调和酒、软饮料、水果装饰，每类可多选/留空；跨 Tab 保存选择，基础冰水独立选择。
- 结果在点击开始组合后生成，修改选择提示重新组合；只列材料池可制作的经典酒。
- 7 种材料浏览器案例得到 1 杯经典和 12 种框架组合，覆盖金酒/伏特加、汤力水/可乐、干味美思及橙片装饰与留空版本。
- 临时真实服务测试覆盖新框架、完整候选、多基酒/多软饮、空分类、零酒精、所用原料必须来自并集和每张新配方备份校验。
- 390×844 手机视口四个 Tab 与双列材料按钮显示正常，无横向溢出；构建通过，临时测试文件和编译产物已删除。

## 完成入口与抽卡时序

- 材料面板最后一个 Tab 提供“我选好了，看看能调什么”，底部吸附“我选好了，开始调酒”，点击后滚动并聚焦结果。
- 浏览器验证 drawing 阶段没有插画节点且文字隐藏；revealing 阶段插画节点出现且文字同时执行 reveal-copy；revealed 阶段完整显示。
- 跳过动画立即进入 revealed 并展示插画和文字。动画关闭/减少动态继续直接显示完整结果。
