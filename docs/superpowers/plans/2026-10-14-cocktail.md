# 鸡尾酒 MVP Implementation Plan

**Goal:** 在现有网站交付完整鸡尾酒体验，保留 60 张已有配方。

**Architecture:** 共用 Recipe、详情和播放器；材料规则与数据迁移放在独立服务，材料页面只协调输入输出。

**Tech Stack:** React + TypeScript + Vite + JSON + localStorage + SVG。

- [x] 在临时 Node 测试中定义库存边界、锁定/排除、酒精限制和导入安全的验收断言，先验证现有功能不满足新需求。
- [x] 修改 src/types.ts、动画类型；新增 src/services/cocktails.ts（字典、匹配、组合）和 src/services/localData.ts（记录和导入验证）。
- [x] 查阅 15 张 IBA 原页，将核验后的自编酒谱加入 public/data/recipes.json，新增 public/data/ingredients.json 与 docs/cocktail-sources.md。
- [x] 在独立 CocktailScene 和成品图中实现 8 个模板，更新 scripts/validate-animations.mjs 和配方门禁。
- [x] 新增材料调酒页面、记录面板和数据迁移面板；接入 App 的抽卡/图鉴/收藏与 RecipeDetail，补充局部 CSS。
- [x] 运行临时逻辑测试、npm run build，检查手机/桌面交互、刷新和缓存后的离线功能；修复实际发现的问题。
- [x] 更新 README、验收证据和本计划，删除临时测试，检查 git diff，仅交付工作区改动。

校验命令：`npm run build`；通过条件为类型检查、75 条配方/材料/动画门禁和 Service Worker 生成全部退出 0。业务边界使用 Node assert 与临时编译后的 TypeScript 模块验证，浏览器使用当前可用的本地浏览器控制能力，超时不少于 30 秒。
